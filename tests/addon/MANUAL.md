# 綠皮冒險工具箱 實機測試步驟（GF-001-D、GF-000-A、GF-000-B、GF-000-C、GF-008-A）

由 owner 在台服《魔獸世界：永恆》（Interface 16001）執行。每一項做完在 □ 打勾，失敗的項目記下截圖或聊天框內容，回報到 `collab/LOG.md` 或 QUESTIONS。

## 0. 離線測試（不需要遊戲）

```
python -m pip install --user lupa      # 只需一次
python tests/addon/run_lupa.py         # 預期最後一行：N passed, 0 failed（N 依版本而定）
```

若樣本檔需要重產：`python tests/addon/run_lupa.py --fixture`。

## 1. 部署（需 owner 同意後才執行）

1. 完全離開遊戲。
2. 在專案根目錄執行：
   ```
   powershell -File scripts\deploy-addon.ps1 -Name GreenFangToolkit
   ```
   腳本會把 `addon\GreenFangToolkit` 複製到 `D:\World of Warcraft\_forever_\Interface\AddOns\GreenFangToolkit`。第一次部署沒有舊版，所以不會產生備份。
3. **第一次登入時先保留舊的 GFGuildRoster 為啟用**。遊戲只會在插件啟用時載入它的 SavedVariables，新插件要讀得到 `GFGuildRosterDB` 才能搬資料。確認第 4 節的遷移成功後，再到插件清單停用 GFGuildRoster。
4. 建議先在遊戲內輸入 `/console scriptErrors 1`，讓 Lua 錯誤直接顯示。

回復：在角色選擇畫面的「插件」清單取消勾選「綠皮冒險工具箱」即可，不需要刪檔。要整個移除時由 owner 自行刪除 AddOns 底下的 `GreenFangToolkit` 資料夾；`WTF` 裡的 `GreenFangToolkit.lua` 可以留著。

## 2. 載入與第一次說明

- □ 角色選擇畫面的插件清單顯示「綠皮冒險工具箱」，作者「綠皮與獠牙冒險事務所」，沒有「過期」或「不相容」標示
- □（0.9.1 起作廢，見 §3l） 進入遊戲約 3 秒後，聊天框出現**一行**：「綠皮冒險工具箱會在你下線後，透過 GF Sync 把角色資料同步到公會網站；`/gftk sync off` 可關閉。」
- □ 沒有跳出任何視窗，沒有 Lua 錯誤
- □ `/reload` 或換角色登入後，這行說明**不再出現**（同帳號只顯示一次）

## 3. 名冊視窗（沿用 v0.3.1）

- □ `/綠皮` 也能開啟（中文斜線指令，**需要實機確認遊戲接受**）
- □ `/gftk help` 或 `/gftk 亂打` 顯示兩行用法說明
- □ 小地圖外圈的按鈕（0.6.2 起是背包圖示）：左鍵開關工具箱、拖曳沿外圈移動、右鍵回到左下方。小地圖上只有這一個綠皮按鈕（舊的 GFGuildRoster 停用後）

- □ 搜尋框可依名字、職業、專業、位置篩選

## 3e. 所在地與圖形化介面（GF-001-D6，0.7.0 起）

**所在地**
- □（0.9.1 起作廢，見 §3l） 第一次登入 0.7.0：聊天框出現**一行**說明，提到「角色資料與所在地」，以及可以在「設定」關閉；沒有跳視窗。之前看過舊說明的帳號也會再看到一次，之後不再出現
- □（0.9.1 起作廢，見 §3l） 「設定」頁：在同步按鈕右邊有「分享我的角色所在地：開啟（點一下關閉）」，預設是開啟
- □ 點一下變成「關閉（點一下開啟）」，聊天框說明已關閉；換同帳號的另一個角色登入，仍然是關閉
- □ 在不同地區下線，SV 裡該角色 `character.self` 的 `payload.location` 是下線那一刻的 `zone`／`subZone`（例如奧格瑪／力量谷）；在主城外空曠處沒有子區域時沒有 `subZone`
- □ 關閉分享後下線：`character.self` 沒有 `location`
- □ `roster.snapshot` 的成員**沒有** `location`、`zone`、`online`

**我的角色（新的一頁，左側導覽第二個）**
- □ 左上角是職業圖示（不是綠色方塊或問號），角色名字是職業顏色，下面一行是「等級 N　種族　職業」
- □（0.9.1 起作廢，見 §3l） 公會與會階、所在地各一行；關閉分享時顯示「所在地：不分享（可以在「設定」開啟）」
- □ 每個專業一列：左邊是專業圖示，右邊是名稱和綠色進度條，條上寫「目前 / 上限」（例如「151 / 225」），長度和比例相符
- □ 釣魚、烹飪、急救也有圖示和進度條；學了新技能點或升級後重開這頁，數字會更新
- □ 沒有學任何專業的角色：顯示「沒有讀到專業技能。」，不會報錯

**公會名冊**
- □ 欄位順序：角色、會階、種族、職業、專業技能、等級、位置、狀態；都沒有被截斷或重疊
- □ 角色名字和職業文字是職業顏色；職業前面有 16 像素的職業圖示
- □ 專業技能欄：每個專業前面有小圖示（採礦、鍛造等）；只有名稱、對照不到圖示的會只顯示文字；完全沒有專業的顯示原本的「未記錄」字樣
- □ 等級置中；狀態「在線」是綠色、「離線」是灰色；會階是淡金色
- □ 點「會階」標題：會長排最前面，再點一次反過來
- □ 搜尋、排序、匯出照常；匯出內容和 0.6.6 一樣（沒有圖示、沒有會階序號）

**共通**
- □ 以上畫面都沒有方框字或問號圖示（GF-000-D）
- □ 小地圖按鈕、睡袋路線不受影響

9. □ 公會裡有人也裝了工具箱的話，請他看訂單頁：**看不到**你的測試單

## 3probe. 功能探測（GF-PROBE）

不用戰鬥，每步打完會跳出一個可複製的視窗；最後只要貼一次。

1. 上線後打 `/gftk probe`。
2. 走到銀行 NPC 打開銀行，打 `/gftk probe bank`。有公會銀行的話，打開公會銀行再打一次 `/gftk probe bank`。
3. 選一位在線的公會成員當目標，右鍵「觀察」，看到裝備視窗後關掉，再打 `/gftk probe`。
4. （順便）打開任一個專業視窗再關掉。
5. 打 `/gftk probe copy`，按 Ctrl+A、Ctrl+C，整段貼給 claude-pm。

結果只有「有沒有這個功能、回傳什麼型別、幾個」，沒有角色名、GUID 或背包內容。同步與診斷視窗最下面的「功能探測」也看得到摘要。
