# 綠皮冒險工具箱 實機測試步驟（GF-001-D、GF-000-A、GF-000-B、GF-000-C、GF-008-A）

由 owner 在台服《魔獸世界：永恆》（Interface 16001）執行。每一項做完在 □ 打勾，失敗的項目記下截圖或聊天框內容，回報到 `collab/LOG.md` 或 QUESTIONS。

## 0. 離線測試（不需要遊戲）

```
python -m pip install --user lupa      # 只需一次
python tests/addon/run_lupa.py         # 預期最後一行：N passed, 0 failed（N 依版本而定）
```

若樣本檔需要重產：`python tests/addon/run_lupa.py --fixture`。

## 1. 部署（需 owner 同意後才執行）

1. 完全離開遊戲。
2. 在專案根目錄執行：
   ```
   powershell -File scripts\deploy-addon.ps1 -Name GreenFangToolkit
   ```
   腳本會把 `addon\GreenFangToolkit` 複製到 `D:\World of Warcraft\_forever_\Interface\AddOns\GreenFangToolkit`。第一次部署沒有舊版，所以不會產生備份。
3. **第一次登入時先保留舊的 GFGuildRoster 為啟用**。遊戲只會在插件啟用時載入它的 SavedVariables，新插件要讀得到 `GFGuildRosterDB` 才能搬資料。確認第 4 節的遷移成功後，再到插件清單停用 GFGuildRoster。
4. 建議先在遊戲內輸入 `/console scriptErrors 1`，讓 Lua 錯誤直接顯示。

回復：在角色選擇畫面的「插件」清單取消勾選「綠皮冒險工具箱」即可，不需要刪檔。要整個移除時由 owner 自行刪除 AddOns 底下的 `GreenFangToolkit` 資料夾；`WTF` 裡的 `GreenFangToolkit.lua` 可以留著。

## 2. 載入與第一次說明

- □ 角色選擇畫面的插件清單顯示「綠皮冒險工具箱」，作者「綠皮與獠牙冒險事務所」，沒有「過期」或「不相容」標示
- □（0.9.1 起作廢，見 §3l） 進入遊戲約 3 秒後，聊天框出現**一行**：「綠皮冒險工具箱會在你下線後，透過 GF Sync 把角色資料同步到公會網站；`/gftk sync off` 可關閉。」
- □ 沒有跳出任何視窗，沒有 Lua 錯誤
- □ `/reload` 或換角色登入後，這行說明**不再出現**（同帳號只顯示一次）

## 3. 名冊視窗（沿用 v0.3.1）

- □ `/綠皮` 也能開啟（中文斜線指令，**需要實機確認遊戲接受**）
- □ `/gftk help` 或 `/gftk 亂打` 顯示兩行用法說明
- □ 小地圖外圈的按鈕（0.6.2 起是背包圖示）：左鍵開關工具箱、拖曳沿外圈移動、右鍵回到左下方。小地圖上只有這一個綠皮按鈕（舊的 GFGuildRoster 停用後）

- □ 搜尋框可依名字、職業、專業、位置篩選

## 3e. 所在地與圖形化介面（GF-001-D6，0.7.0 起）

**所在地**
- □（0.9.1 起作廢，見 §3l） 第一次登入 0.7.0：聊天框出現**一行**說明，提到「角色資料與所在地」，以及可以在「設定」關閉；沒有跳視窗。之前看過舊說明的帳號也會再看到一次，之後不再出現
- □（0.9.1 起作廢，見 §3l） 「設定」頁：在同步按鈕右邊有「分享我的角色所在地：開啟（點一下關閉）」，預設是開啟
- □ 點一下變成「關閉（點一下開啟）」，聊天框說明已關閉；換同帳號的另一個角色登入，仍然是關閉
- □ 在不同地區下線，SV 裡該角色 `character.self` 的 `payload.location` 是下線那一刻的 `zone`／`subZone`（例如奧格瑪／力量谷）；在主城外空曠處沒有子區域時沒有 `subZone`
- □ 關閉分享後下線：`character.self` 沒有 `location`
- □ `roster.snapshot` 的成員**沒有** `location`、`zone`、`online`

**我的角色（新的一頁，左側導覽第二個）**
- □ 左上角是職業圖示（不是綠色方塊或問號），角色名字是職業顏色，下面一行是「等級 N　種族　職業」
- □（0.9.1 起作廢，見 §3l） 公會與會階、所在地各一行；關閉分享時顯示「所在地：不分享（可以在「設定」開啟）」
- □ 每個專業一列：左邊是專業圖示，右邊是名稱和綠色進度條，條上寫「目前 / 上限」（例如「151 / 225」），長度和比例相符
- □ 釣魚、烹飪、急救也有圖示和進度條；學了新技能點或升級後重開這頁，數字會更新
- □ 沒有學任何專業的角色：顯示「沒有讀到專業技能。」，不會報錯

**公會名冊**
- □ 欄位順序：角色、會階、種族、職業、專業技能、等級、位置、狀態；都沒有被截斷或重疊
- □ 角色名字和職業文字是職業顏色；職業前面有 16 像素的職業圖示
- □ 專業技能欄：每個專業前面有小圖示（採礦、鍛造等）；只有名稱、對照不到圖示的會只顯示文字；完全沒有專業的顯示原本的「未記錄」字樣
- □ 等級置中；狀態「在線」是綠色、「離線」是灰色；會階是淡金色
- □ 點「會階」標題：會長排最前面，再點一次反過來
- □ 搜尋、排序、匯出照常；匯出內容和 0.6.6 一樣（沒有圖示、沒有會階序號）

**共通**
- □ 以上畫面都沒有方框字或問號圖示（GF-000-D）
- □ 小地圖按鈕、睡袋路線不受影響

9. □ 公會裡有人也裝了工具箱的話，請他看訂單頁：**看不到**你的測試單

需要兩個角色，都在本會、都裝同一版：**W**（掛職工單的人，等級落在地城範圍內）和 **L**（開冒險單的人）。兩人都上線。

1. □ W：主視窗右上角「業務通知」→「設定」：看到「職工單配對」打勾，下面縮排三個選項「副職責也算」「共同任務也算」打勾、「配對時聊天框一行」沒勾；「調貨所配對」「需求雷達」「聊天框提示」還在

### 配對與跳轉

3. □ L：開一張同地城、時段「現在」、還缺坦的冒險單
4. □ W：幾秒內（最多約 2 分鐘）鈴鐺有未讀數字；清單有一則「職工單配對：血色修道院：墓地 現在… 缺坦」

12. □ W 移除自己的職工單：所有「職工單配對」通知消失
13. □ 冒險單時段結束（或 W 的職工單到期）後，通知自己消失

### 設定

14. □ W 取消「職工單配對」：現有的配對通知消失，之後 L 再開單也不通知；換另一個角色登入，這個設定仍是預設（各角色各自記）
15. □ W 勾「配對時聊天框一行」：L 開新單時聊天框多一行「綠皮…職工單配對：…」，一分鐘內最多一行
16. □ W 掛的職工單只選任務（不選地城），L 開同任務的冒險單：會通知；取消「共同任務也算」後不通知

### 戰鬥

17. □ W 在戰鬥中時 L 開單：戰鬥中沒有通知、沒有聊天框行；脫戰後才出現

### 隱私

18. □ `/gftk diag` 或存檔裡找不到新的上傳種類；配對結果只在 W 的 `GreenFangToolkitDB.notify`

## GF-011-B 天賦樹與訂單「製作」（只做過離線測試，未實機驗證）

需要 **A**（自己）和 **B**（會友，最好不同職業），都裝同一版、都點過天賦。「製作」要一張你接的委託單（可以用測試模式下給自己的單）。

### 先探測（單人，2 分鐘）

1. □ 輸入 `/gftk probe`，在 `apis` 段找這幾個，抄下各是 function 還是 nil：`PlayerSpellsUtil.InspectLoadout`、`PlayerSpellsUtil.OpenToClassTalentsTab`、`SetItemRef`、`ProfessionsUtil.OpenProfessionFrameToRecipe`、`C_TradeSkillUI.OpenRecipe`、`OpenProfessionUIToSkillLine`、`C_TradeSkillUI.OpenTradeSkill`（**不要貼帳號名稱**）

### 天賦樹

2. □ 名冊點自己那一列的「職責」格，開「職工檔案」：有「天賦　x/y/z」和「天賦樹」。按「天賦樹」：打開平常的天賦視窗（和按 N 一樣），可以照常改天賦
3. □ 關掉後，在天賦視窗改一點天賦並套用：不會出現「介面功能因插件而失敗」之類的錯誤（有的話截圖，然後 `/reload`）
4. □ 開 B 的職工檔案，按「天賦樹」：打開遊戲的天賦視窗，顯示的是 **B 的職業和配點**（只能看，沒有套用鈕），點數和 B 自己天賦視窗一樣。記下：有沒有打開、職業對不對、點數對不對
5. □ 第 4 步如果沒打開而是聊天輸入框出現「[天賦：B …]」連結：表示遊戲不收那串天賦。按 ESC 取消，把第 1 步那幾行和畫面給 claude-pm
6. □ 名冊在 B 那一列按右鍵：有「天賦樹」，效果同第 4 步
7. □ 沒裝新版的會友（沒收到天賦）：職工檔案「天賦　未知」，「天賦樹」是灰的、按不下去、滑鼠移上去不會亮
8. □ 進戰鬥（打一隻怪）時開自己的職工檔案：「天賦樹」是灰的；脫戰後重開職工檔案就能按
9. □ 職工檔案按 ESC 或右上 ✕ 會關；天賦視窗也照遊戲平常的方式（ESC）關

### 委託單「製作」

10. □ 找一張你是工匠、已「接單」（製作中）的單（沒有的話：設定開測試模式，給自己下一張你有的專業的單，按「接單」）。那一列多一個專業圖示＋「製作」
11. □ 按「製作」：打開那個專業的視窗，左邊清單選好的是那張單的配方。只是打開，沒有開始製作、單子狀態不變
12. □ 如果打開了專業視窗但沒有選到那個配方：記下來（表示只用到「開專業」那一層），連同第 1 步的結果給 claude-pm
13. □（不好做就跳過，離線測試已涵蓋）你接了單之後放棄那個專業、或用沒有那個專業的分身看同一張單：「製作」是灰的、圖示變灰、按不下去
14. □ 戰鬥中按「製作」沒反應；脫戰後可以按
15. □ 「等接單」的單、你是客人的單、已交付（待驗收）的單：都沒有「製作」

### 關掉工具箱後不留浮動提示（0.16.5 截圖的「急救 38 / 75　配方 3 個」）

16. □ 打開名冊，滑鼠移到**自己那一列**的專業圖示（出現「急救 / 38 / 75 / 配方 n 個」那種提示，圖示有白框）。滑鼠不要移開，按 ESC 關掉工具箱：提示和白框一起消失，畫面中間什麼都沒留
17. □ 同第 16 步，改按主視窗右上 ✕（或小地圖按鈕）關：一樣什麼都沒留
18. □ 關掉後等 1～2 分鐘（讓名冊自己更新一次，例如有會友上下線），在畫面中間原本名冊的位置移動滑鼠：不會冒出專業提示，也沒有看不見但點得到的東西（點了不會開專業視窗）

## GF-FIX-C 名冊掃描、配方索引、下單選配方（只做過離線測試，未實機驗證）

重點：名冊、配方、下單清單要和以前一樣快反映變動，只是「沒變就不重做」。大公會最好（人越多越看得出差別）。

### 名冊即時性

1. □ 開著名冊頁，請一位會友上線或下線：約 1 秒內那一列的在線狀態變了（和以前一樣快）
2. □ 會友升級、換區：下一次名冊更新（通常幾秒內）就看到新的等級、區域
3. □ 有人入會或退會：名冊人數和清單立刻跟著變
4. □ 名冊頁開著、什麼都沒變的時候（大家都掛著不動）：拖動捲軸、看畫面，不會每隔幾秒頓一下
5. □ 戰鬥中有人上線：脫戰後約 1 秒名冊更新
6. □ 按名冊的「更新」：照常出現「名冊已更新：N 位角色」或錯誤說明
7. □ 登入後 2 分鐘內：同步、訂單、冒險、價格照常啟動（同步與診斷視窗看得到各自的狀態），和以前一樣
8. □ 登出或 /reload 後讓 GF Sync 上傳：網站的名冊更新時間是你最後一次在線時的時間（不是更早）

### 配方與下單

9. □ 配方頁搜尋框打字：打第一個字就出結果，連續打字時畫面最慢 0.15 秒跟上，最後顯示的是完整的字
10. □ 訂單頁「＋下單」選配方的搜尋框：同上；打字不會卡
11. □ 有會友上線、或同步收到新的配方：配方頁、下單清單裡馬上看得到（會做的人的在線圖示也跟著變）
12. □ 打開自己的專業視窗：配方立刻存進去（配方頁看得到自己）；連續製作、在專業視窗裡打字時不會一直卡
13. □ 訂單頁從「我的業務」打開一張單：那一列有淡黃色的高亮（以前看不到）
14. □ 訂單頁上下捲動：順暢；按鈕（接單、交付、製作…）照常有效

### 其他

15. □ 登入或 /reload 時已經有職工單：任務日誌還沒載入時，職工單上的任務不會被清空（登入後看職工單仍是你的任務）
16. □ 交掉日誌裡最後一個任務：職工單上的那個任務照常拿掉
17. □ 同步與診斷視窗開著時，「名冊天賦」那一行照常顯示，改天賦後幾秒內跟著變
